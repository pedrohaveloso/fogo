# Pesquisa

Pesquisa feita em 22/10/2026 para orientar a revisão da interface e da entrega. Os arquivos descrevem o projeto como ele estava nesse dia. Vários problemas listados em "Problemas prováveis" e "Gaps" foram corrigidos depois, e o histórico do Git mostra quando.

- `products.md`: centros de operações, plataformas de segurança, gestão de trânsito, telemetria de frota e manutenção, e o que cada um ensina para o F.O.G.O.
- `practices.md`: boas práticas de interface (ISA-101, ISA-18.2, consciência situacional, WCAG 2.2, linguagem simples) e o checklist usado na revisão das telas.
- `geography.md`: fontes de dados geográficos de Marília e o plano para os limites de bairro.
- `delivery.md`: configuração para IA, documentação e itens de entrega.
